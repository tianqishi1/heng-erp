## 一、系统现在能做什么（业务视角）

| 能力 | 说明 | 在哪里用 |
|---|---|---|
| 一句话开单 | 对助手说"给华东李总发200台A100，按上次的价格，含税"，系统自动找到客户、取上次成交价、算好税，生成**待确认的订单卡片**，人点确认才真正建单 | 工作台 |
| 同名客户不瞎猜 | 有两个"李总"时，助手会反问让你选，而不是猜一个 | 工作台 |
| 订单全流程 | 新建（草稿）→ 确认出库（自动扣库存、自动生成收入凭证）→ 开票 → 收款 → 取消（自动红冲凭证、回补库存） | 销售订单页 |
| 价税自动分离 | 含税价自动拆成不含税金额+税额，精确到分；税率按业务日期适用当年政策（2019 年 16% / 2026 年 13% 可复现） | 全局 |
| 开票（演示通道） | 对已确认订单开具发票，税额与订单自动勾稽；**当前为沙箱演示，未接真实税务平台** | 订单行"开票" |
| 收款双人审批 | 收款属高风险事项，必须两位**不同**审批人先后批准才执行（四眼原则）；同一人批两次会被拒绝 | 审批中心 |
| 审批中心 | 所有待批事项集中展示：业务摘要（客户/商品/金额）、风险等级、审批进度（1/2 人） | 审批中心 |
| 经营问数 | "上月华东区收入多少"→ 数字+统计口径+可下钻的单据号，**数字不是 AI 编的**，是按固定口径算出来的 | 工作台 |
| 账务体检 | 四项持续自动校验：订单金额勾稽、借贷平衡、库存账实一致、发票税额勾稽；任何一项异常会告警 | 账务体检页 |
| 全程留痕 | 每笔操作记录谁做的、依据什么、AI 参与过没有；单据可反查完整操作链 | 后台接口（界面化在 M1） |
| 信用控制 | 客户超信用额度时订单直接被拒，并提示原因 | 新建订单时 |
| AI 断了也能用 | 智能助手不可用时，所有表单/列表/审批功能完全不受影响 | 全局 |

## 二、现在还不能做什么（边界，避免误解）

- 没采购、MRP/生产、HR、固定资产、成本核算、合并报表、纳税申报直连、银企直连。
- 没登录和权限管理：**当前身份是自报的**（右上角下拉切换），仅供内网演示。
- 发票是演示通道，不产生真实数电票。
- 智能助手当前是"规则模板兜底"模式（离线可跑、可预测），**尚未接真实大模型**；接口已就位，配置后即启用。
- 界面是单文件演示工作台，不是最终产品 UI（最终为元数据驱动的表单/列表/看板/报表体系）。
- 数据库是 SQLite 演示库，不是生产库（生产为 PostgreSQL+行级隔离）。
- 单机单进程，无高可用部署。

## 三、变更点（本次迭代改了什么）

### 界面与交互（回应试用反馈）
1. **全面去技术化**：不再向用户展示 JSON、审批单号、动作名、模型名、置信度等；金额千分位、状态中文徽标、客户/商品显示名称。
2. **双击"落库"显示 reject 的问题**：
   - 后端行为是**正确的防重复保护**——审批单状态机为 待审批→已批准→已执行，第二次点击会被拒绝（避免重复建单/重复付款）。
   - 问题在前端：按钮没禁用、报错直接弹原始 JSON。**已修复**：点击即禁用按钮；成功后卡片变为"✔ 已确认，订单 SO-xxx 已创建"；若仍收到重复操作拒绝，显示"该卡片已处理过，请勿重复操作"。
3. 从"聊天+一张表"升级为小型 ERP 工作台：七个页面（工作台/销售订单/库存/会计凭证/发票/审批中心/账务体检）、订单明细抽屉（行+关联凭证+发票）、凭证抽屉（科目借贷）、新建订单表单、订单行操作（确认出库/开票/收款/取消）、身份切换（演示四眼审批）。
4. 报错全部翻译为业务语言（如"客户信用额度不足，请减少数量或联系财务调整额度"）。

### 接口
- 新增：审批中心列表（业务化摘要）、单据按字段筛选、账务体检明细（检查项+条数+结论）。

### 工程（此前 M0 已落地，此处备忘）
- 业务表改为 (租户, ID) 复合主键，修复跨租户撞键；内存库跨线程共享连接；金额字符串在断言中按十进制运算。

## 六、给试用者的三个说明

1. **为什么之前界面像"聊天+落库"**：M0 的目标是验证"AI 提案→人审→确定性落库→自动记账"这条核心链路是否成立，界面只是工程验证壳。正式 ERP 的界面是元数据驱动的单据/列表/看板/报表体系（Odoo/用友/金蝶皆如此），在 M1 用 React+AntD 落地；本次已先把演示壳升级为可走完整业务流的小型工作台。
2. **为什么点第二次会 reject**：那是防重复执行保护在起作用（同一审批单只能执行一次），不是数据出错。现在按钮会禁用、卡片会变成"已确认+单号"，不会再出现裸 reject。
3. **AI 现在有多"真"**：当前助手跑在离线兜底档（规则模板），行为可预测、零成本、可评测；接真实大模型后，同一套行动卡/审批/审计/评测约束原样生效——**换模型不换规则**。
