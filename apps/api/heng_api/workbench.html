账务体检

系统持续自动校验：订单金额勾稽、借贷平衡、库存账实一致、发票税额勾稽。任何一项不通过都会告警并暂停相关自动化。

系统自进化

闭环：生产留痕自动挖掘失败案例 → 生成候选改进 → 沙箱全量评测（黄金集零退化） → 人工审批 → 本租户灰度 → 全量或一键回滚。进化对象仅限话术/知识等外围资产；账务内核、权限、代码永不自动变更。护栏：每周≤10 个进化单、同资产 72 小时冷却。

优化点案例池

进化单（候选 → 审批 → 灰度 → 全量）

扩展包（不改动核心代码即可扩展）

扩展包 = 元数据（新字段/新动作/新规则）+ 强制评测集。安装即生效，升级兼容由契约保证。示例：trade_priority 为订单增加"优先级"。

说明

当前为 M1 演示环境：数据库为演示库、发票为沙箱通道、智能助手运行于离线兜底模式（接入真实大模型后，同一套审批/审计/评测约束原样生效）。生产部署将提供 PostgreSQL 行级隔离、高可用与 WORM 审计。
